Sur le PC atelier (Windows)
  1. Ferme Network Debug Assistant (sinon le port est déjà pris).
  2. Place le TXT + le script dans le même dossier, ex. C:\aya_laser\
  3. Ouvre PowerShell dans ce dossier.
  4. Test 3 codes d’abord :
python laser_tcp_sender.py --host {{ laser_host }} --port {{ laser_port }} --file aya_codes_machine.txt --limit 3 --mode interval --interval-ms 1000

Lot complet (reprise auto si coupure) :

python laser_tcp_sender.py --host {{ laser_host }} --port {{ laser_port }} --file aya_codes_machine.txt --mode interval --interval-ms 1000

Si tu confirmes que SMX arrive après chaque code (pas seulement en heartbeat) :

python laser_tcp_sender.py --host {{ laser_host }} --port {{ laser_port }} --file aya_codes_machine.txt --mode smx --wait-smx-ms 3000
Le fichier laser_progress.json mémorise le dernier code envoyé. Relance la même commande pour reprendre. Pour tout recommencer : ajoute --reset-progress.
Vérifier SMX (expérience rapide)
  1. Dans Network Debug Assistant, connecte-toi à {{ laser_host }}:{{ laser_port }}.
  2. Observe si SMX arrive sans rien envoyer (heartbeat).
  3. Envoie une seule fois : SM https://monuniversaya.com/scan?code=test1\r\n
  4. Note ce qui apparaît juste après, avec l’heure.
  5. Si SMX arrive en continu → garde --mode interval.
    Si SMX arrive clairement après chaque envoi → tu peux utiliser --mode smx.
